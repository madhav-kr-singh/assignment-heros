Foundations

A design system for candidate confidence.

Color, type and component tokens that power Prepr.ai. Built on a warm coral primary, ink-based neutrals and semantic signals — all tuned to meet WCAG AA contrast at every interactive scale.

01 · Color

A warm, human palette.

Coral leads — it's optimistic, energetic, and rare in SaaS. Ink neutrals keep things premium. Semantic colors are reserved for signal, never decoration.

10 families · 92 shades

Primary · Coral --coral-*

The brand voice. Use 500 for CTAs, 600 on hover/press, 50–100 for tinted surfaces, 700+ on light text for AA compliance.

Neutrals · Ink --ink-*

A single greyscale ramp handles text, borders and surfaces. 900 for headlines, 500–600 for body, 200 for borders, 50–100 for fills.

Semantic colors --success / --warning / --error / --info

Used for status: form validation, toasts, metrics, badges. Always pair with a background tint (*-bg) for legibility on light canvases.

Recommended combinations

Three approved surface treatments. Don't invent new pairings — these are the combinations we've verified for contrast and brand cohesion.

LIGHT / DEFAULT
Practice with AI — instantly.

Ink-900 headlines on white. Coral 500 for action.

DARK / ACCENT
Premium feature sections.

Ink-900 canvas + white text + coral-400 accent for headings.

BRAND / CTA
Full-bleed moments of action.

Coral gradient. Reserved for final CTAs & hero moments.

Accessibility & readability

Line length: 45–75 characters

Long-form copy clamps to ≈640px at --text-body — approximately 66 characters per line.

Minimum body size: 14px

Never below 14px for reading content. 12px reserved for tabular captions and mono metadata only.

Italic serifs, used sparingly

Italic serifs are harder to scan for dyslexic readers — reserved for 1–2 words per headline, never body copy.

Respect user zoom

All sizes defined in rem/em so browser text-zoom (up to 200%) scales the product gracefully.

Line-height ≥ 1.5 for body

Meets WCAG 1.4.12 for text spacing. Headings can go tighter (1.02–1.1) for visual impact.

Focus states always visible

4px coral-500 @ 18% opacity outline on any focused control. Never suppressed with outline:none.

06 · Tokens

Copy, paste, ship.

Every value above is a CSS custom property. Drop these into your project and you have the system.

/* design-tokens.css — colors */
:root {
  /* Primary · coral */
  --coral-50:  #FFF4EF;
  --coral-100: #FFE4D6;
  --coral-200: #FFC9AE;
  --coral-300: #FFA67E;
  --coral-400: #FF8450;
  --coral-500: #FF6B35; /* primary */
  --coral-600: #F05423;
  --coral-700: #C33E14;
  --coral-800: #8F2E0F;

  /* Neutrals · ink */
  --ink-900: #0B0D12;
  --ink-700: #232734;
  --ink-500: #5B6272;
  --ink-300: #B8BDC8;
  --ink-100: #F1F3F7;

  /* Semantic */
  --success: #12B76A;
  --warning: #F59E0B;
  --error:   #E24B4B;
  --info:    #3B82F6;
}
/* design-tokens.css — typography */
:root {
  --font-sans: 'Geist', 'Inter', system-ui;
  --font-display: 'Instrument Serif', serif;
  --font-mono: 'JetBrains Mono', ui-monospace;

  /* Scale */
  --text-display: clamp(40px, 6vw, 76px);
  --text-h1:      clamp(32px, 4.2vw, 44px);
  --text-h2:      clamp(26px, 3.2vw, 32px);
  --text-h3:      24px;
  --text-body-lg: 18px;
  --text-body:    16px;
  --text-body-sm: 14px;
  --text-caption: 12px;

  /* Leading */
  --leading-tight: 1.05;
  --leading-snug:  1.3;
  --leading-body:  1.5;

  /* Tracking */
  --track-tight: -0.028em;
  --track-body:  0;
  --track-caps:  0.08em;
}
/* SCSS map alternative */
$colors: (
  primary: (50: #FFF4EF, 500: #FF6B35, 600: #F05423, 700: #C33E14),
  ink:     (50: #F8F9FC, 500: #5B6272, 900: #0B0D12),
  semantic:(success: #12B76A, warning: #F59E0B, error: #E24B4B)
);

/* Usage: */
.btn-primary {
  background: map-get(map-get($colors, primary), 500);
  color: #fff;
  &:hover { background: map-get(map-get($colors, primary), 600); }
}
One source of truth

Never hard-code a hex, size or shadow in components. If a value isn't a token, it's a bug — log it and extend the system.
